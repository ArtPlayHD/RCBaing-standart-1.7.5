Цветной TFT (ST7735) — базовый вывод

Цветной экран хорош для визуализации уровней, прогресса, игровых элементов (как в RCBlocks или Minecraft‑клоне).

#include 
#include 

#define TFT_CS 10
#define TFT_RST 9
#define TFT_DC 8
Adafruit_ST7735 tft = Adafruit_ST7735(TFT_CS, TFT_DC, TFT_RST);

void setup(void) {
  tft.initR(INITR_BLACKTAB);
  tft.fillScreen(ST7735_BLACK);
  tft.setTextColor(ST7735_WHITE);
  tft.setTextSize(2);
  tft.setCursor(10, 20);
  tft.println("RCB Zone Active");
  tft.drawRect(10, 50, 100, 30, ST7735_BLUE);
  tft.fillRect(12, 52, 96, 26, ST7735_RED);
  tft.display();
}

void loop() {}

EEPROM — сохранение данных после перезагрузки

Используй это для счётчиков, прогресса, настроек пранка, лунного цикла («Уютный уголок»), уровней. 

Arduino (EEPROM)
#include 

int address = 0; // адрес ячейки
int savedValue = 0;

void setup() {
  Serial.begin(9600);
  savedValue = EEPROM.read(address);
  Serial.print("Loaded value: ");
  Serial.println(savedValue);
}

void loop() {
  static int counter = 0;
  counter++;
  Serial.print("Counter: ");
  Serial.println(counter);

  // Сохраняем только если значение изменилось (чтобы не изнашивать EEPROM)
  int currentSaved = EEPROM.read(address);
  if (currentSaved != counter) {
    EEPROM.update(address, counter); // update пишет только при разнице
  }

  delay(1000);
}

Совет: для больших данных (строки, float) используй EEPROM.put() и EEPROM.get().

Счётчик с выводом на TFT (пример интеграции)

Объединяем TFT и EEPROM: счётчик сохраняется и отображается на экране. 

Arduino (TFT + EEPROM)
#include 
#include 
#include 
#include 

#define TFT_CS 10
#define TFT_RST 9
#define TFT_DC 8
Adafruit_ST7735 tft = Adafruit_ST7735(TFT_CS, TFT_DC, TFT_RST);

const int ADDR = 0;
int counter = 0;

void setup() {
  tft.initR(INITR_BLACKTAB);
  tft.fillScreen(ST7735_BLACK);
  counter = EEPROM.read(ADDR);
  drawScreen();
}

void drawScreen() {
  tft.fillScreen(ST7735_BLACK);
  tft.setTextColor(ST7735_WHITE);
  tft.setTextSize(2);
  tft.setCursor(20, 40);
  tft.print("Count: ");
  tft.print(counter);
  tft.display();
}

void loop() {
  counter++;
  EEPROM.update(ADDR, counter);
  drawScreen();
  delay(1000);
}

Пранк в стиле «админ‑панели RCBaing» (идея + пример)

Суть: при включении Arduino показывает «страшную» админ‑панель с ошибками, таймером и мигающими элементами.

  • Экран: «CRITICAL ERROR», «System Locked», таймер до «shutdown».
  • Мигание: менять цвет рамки/фона или инвертировать цвета.
  • Сохранение: сколько раз запускался пранк (через EEPROM).

Пример логики мигания (для цветного TFT): 

Arduino (пранк)
bool blink = false;

void loop() {
  blink = !blink;
  tft.fillScreen(blink ? ST7735_RED : ST7735_BLACK);
  tft.setTextColor(blink ? ST7735_BLACK : ST7735_WHITE);
  tft.setTextSize(2);
  tft.setCursor(5, 60);
  tft.println("CRITICAL ERROR");
  tft.display();
  delay(300);
}

Под стиль RCBaing можно добавить: «Access Denied», «RCBaing Admin Console», «Level 4 Security», «Shutdown in 10s» и т. п.

Частые вопросы и советы

Какой TFT лучше: цветной или чёрно‑белый?

Чёрно‑белый (SSD1306): проще, быстрее, меньше памяти, отлично для текста и пранков. Цветной (ST7735): для графики, уровней, игровых интерфейсов.

Сколько циклов записи выдерживает EEPROM?

Обычно 100 000–1 000 000 циклов. Поэтому используй EEPROM.update() вместо write(), чтобы не перезаписывать одинаковые значения.

Как хранить строки или float?

Используй EEPROM.put(address, variable) и EEPROM.get(address, variable). Следи за адресами и размерами переменных.

Можно ли сделать «прогресс» для «Уютного уголка»?

Да. Сохраняй: день/лунный цикл, состояние кота, прогресс печки, записи дневника (номера записей).
