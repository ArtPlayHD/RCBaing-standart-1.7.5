Пример простого мода на Python (RPG‑конструктор)

Это модуль, который добавляет механику «дневника» в RPG‑конструктор. Его можно положить как mods/diary_mod.py и импортировать в игре. 

Python
class DiaryMod:
    def __init__(self):
        self.entries = []
        self.max_entries = 50

    def add_entry(self, text):
        if len(self.entries) >= self.max_entries:
            self.entries.pop(0)
        self.entries.append(text)

    def get_entries(self):
        return self.entries

    def save(self, path="diary.json"):
        import json
        with open(path, "w", encoding="utf-8") as f:
            json.dump(self.entries, f, ensure_ascii=False, indent=2)

    def load(self, path="diary.json"):
        import json
        try:
            with open(path, "r", encoding="utf-8") as f:
                self.entries = json.load(f)
        except FileNotFoundError:
            self.entries = []

Пример, как мод может добавлять команду в админ‑панель: 

Python (админка)
# В админ‑панели регистрируем команду из мода
def register_mod_commands(admin_panel):
    admin_panel.register_command(
        name="give_item",
        callback=lambda args: give_item(args[0], int(args[1])),
        help="Выдать предмет игроку: give_item <item_id> <count>"
    )
    admin_panel.register_command(
        name="set_time",
        callback=lambda args: set_time(args[0]),
        help="Установить время суток: set_time <day|night|dusk>"
    )

Как упаковать и подключить мод

  1. Создай папку мода: mods/my_mod_name/.
  2. Положи туда mod.json (манифест) и файлы мода.
  3. Если это Python‑мод: основной файл укажи в "entry": "main.py".
  4. В лаунчере/админке добавь поиск модов в папке mods/ по mod.json.
  5. Загружай моды динамически: импортируй main.py или регистрируй команды/классы.

Для Minecraft‑стиля: моды часто упаковывают как .jar с mcmod.info, но для своих проектов (RCB, RPG‑конструктор) удобнее JSON‑манифесты и Python‑модули.
