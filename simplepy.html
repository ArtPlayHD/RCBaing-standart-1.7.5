Документация SimplePy 2.0

SimplePy — набор утилит и вспомогательных функций для быстрой разработки на Python (Tkinter, Pygame, Ursina, скрипты, админки). Версия 2.0 добавляет модульность, улучшенную обработку ошибок и совместимость с Python 3.13.

Установка и подключение

Если у тебя уже есть папка simplepy рядом с проектом, просто импортируй модули: 

from simplepy import easyprint
from simplepy.utils import save_json, load_json
from simplepy.gui import make_window

Для установки через pip (если есть публичный релиз): 

pip install simplepy2

Или вручную: скопируй папку simplepy в корень проекта.

Основные модули

easyprint

Улучшенный вывод в консоль: цветной текст, логирование, форматирование без лишних зависимостей.

utils

Утилиты: работа с JSON, файлами, путями, таймерами, базовыми валидациями.

gui

Быстрые обертки для Tkinter: создание окон, кнопок, меток, простых форм.

game

Вспомогательные функции для Pygame/Ursina: коллизии, таймеры, управление камерой.

easyprint — цветной и удобный вывод

Вместо print() используй easyprint.log(), easyprint.info(), easyprint.error(). 

Python
import simplepy.easyprint as ep

ep.info("Загрузка системы...")
ep.success("Админ-панель готова")
ep.warning("Внимание: низкий уровень энергии")
ep.error("Ошибка соединения с сервером")
ep.debug("Отладочная информация: x=12, y=34")

Цвета работают в большинстве терминалов, включая Windows CMD/PowerShell и VS Code.

utils — работа с данными и файлами

Сохранение и загрузка JSON без лишней возни: 

Python
from simplepy.utils import save_json, load_json

data = {"player": "Artelen", "score": 1230, "level": 4}
save_json("player_data.json", data)

loaded = load_json("player_data.json")
if loaded:
    print("Загружено:", loaded)

gui — быстрое окно на Tkinter

Создай окно за 3 строки: 

Python
from simplepy.gui import make_window, add_button

root = make_window(title="RCB Admin", size=(400, 300), bg="#1a1a1a")
add_button(root, "Запустить сервер", lambda: print("Сервер запущен"))
root.mainloop()

game — утилиты для игр

Пример простой проверки коллизии прямоугольников: 

Python
from simplepy.game import rect_collide

# (x, y, width, height)
player = (100, 100, 32, 32)
enemy = (120, 90, 40, 40)

if rect_collide(player, enemy):
    print("Столкновение!")

Частые вопросы

Можно ли использовать SimplePy в проектах на Ursina?

Да. Импортируй нужные модули и используй утилиты (таймеры, коллизии, сохранение) вместе с объектами Ursina.

А если у меня нет Tkinter?

Модуль gui не обязателен. Остальные модули работают без него. На Windows Tk обычно уже установлен вместе с Python.

Как добавить свой модуль в SimplePy?

Создай файл в папке simplepy/, например my_utils.py, и импортируй его как from simplepy import my_utils.
