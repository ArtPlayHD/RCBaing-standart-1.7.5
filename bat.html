BAT и EXE установщики

Готовые шаблоны BAT для быстрой установки Python‑окружения, зависимостей и запуска проектов. Варианты сборки EXE (PyInstaller) под твои задачи: админки, RPG‑конструкторы, игры (Pygame, Ursina), RCB‑Pad++.

Когда что использовать

Тип Для чего лучше Плюсы Минусы
BAT Быстрая установка, проверка окружения, запуск скриптов, авто‑активация venv Не требует компиляции, легко править, видно шаги Требует установленный Python, виден консольный вывод
EXE (PyInstaller) Готовый бинарный файл для пользователя, без установленного Python Портативность, можно распространять как «игру» или «админку» Большой размер, антивирусные ложные срабатывания, сложнее отладка

BAT‑установщик: базовый шаблон

Этот BAT проверяет наличие Python, создаёт виртуальное окружение, ставит зависимости и запускает проект. Подходит для RCB‑Pad++, админок, RPG‑конструкторов. 

BAT
@echo off
chcp 65001 >nul
title RCB Installer
color 0B

echo ==========================================
echo   RCBaing Installer (Python project)
echo ==========================================
echo.

:: Проверка Python
where python >nul 2>nul
if %ERRORLEVEL% NEQ 0 (
    echo [ОШИБКА] Python не найден в PATH!
    echo Скачайте Python с python.org и добавьте в PATH.
    pause
    exit /b 1
)

echo [OK] Python найден:
python --version
echo.

:: Создание venv
if not exist "venv" (
    echo [*] Создаю виртуальное окружение...
    python -m venv venv
) else (
    echo [OK] Виртуальное окружение уже есть.
)

:: Активация venv
call venv\Scripts\activate.bat

:: Установка зависимостей
if exist "requirements.txt" (
    echo [*] Устанавливаю зависимости...
    pip install -r requirements.txt
) else (
    echo [!] Файл requirements.txt не найден. Пропускаю установку пакетов.
)

echo.
echo ==========================================
echo   Готово! Запускаю проект...
echo ==========================================
python main.py
pause

Под твои проекты: для «Уютного уголка» можно добавить проверку папки data/, для админки — создание папки uploads/.

BAT: установка конкретных библиотек (для твоих задач)

Если нужно быстро поставить стек для разработки (Pygame, Ursina, NumPy и т. п.) под Python 3.13. 

BAT (deps)
@echo off
chcp 65001 >nul
color 0A

echo Установка библиотек для проектов ArtPlayHD/Artelen...

pip install --upgrade pip
pip install pygame
pip install ursina
pip install numpy
pip install pillow

echo Готово. Проверка:
python -c "import pygame, ursina, numpy; print('OK')"
pause

Сборка EXE через PyInstaller

Для игр, админок и конструкторов удобно собрать EXE, чтобы пользователь мог запускать без установленного Python.

  • Установка PyInstaller: pip install pyinstaller
  • Базовый запуск: pyinstaller --onefile main.py
  • С иконкой: pyinstaller --onefile --icon=app.ico main.py
  • Без консоли (GUI): pyinstaller --onefile --noconsole main.py (для Tkinter/Pygame/Ursina)

В папке dist/ появится готовый EXE. Для админок часто используют --noconsole, чтобы не мелькала консоль.

BAT для сборки EXE (автоматизация)

Удобно держать отдельный BAT, который собирает EXE одной кнопкой. 

BAT (build)
@echo off
chcp 65001 >nul
title Build EXE for RCB Project

call venv\Scripts\activate.bat
echo Сборка EXE...
pyinstaller --onefile --noconsole --name RCB_Admin_Panel main.py

if exist "dist\RCB_Admin_Panel.exe" (
    echo [OK] EXE собран: dist\RCB_Admin_Panel.exe
) else (
    echo [ОШИБКА] EXE не найден!
)
pause

Структура проекта для удобной сборки

Чтобы BAT/EXE работали стабильно, держи такую структуру: 

project/
├── main.py                # точка входа
├── requirements.txt      # зависимости
├── assets/               # картинки, шрифты, звуки
├── data/                 # сохранения, конфиги, логи
├── venv/                 # виртуальное окружение (gitignore)
├── install.bat           # установка и запуск
├── build.bat             # сборка EXE
└── README.md

При сборке EXE PyInstaller по умолчанию не видит папки assets/ и data/. Чтобы они попали внутрь, используй --add-data или копируй их вручную рядом с EXE.

Примеры

Админка / RCB‑Pad++

Используй --noconsole и добавь в проект папку data/ для загрузок и логов. 

pyinstaller --onefile --noconsole --add-data "data;data" --name RCB_Pad main.py

Игра на Pygame / Ursina

Важно: все ресурсы (картинки, шрифты) должны лежать в папке рядом с EXE или быть добавлены через --add-data. В коде используй относительные пути: 

import os
def get_path(name):
    base = getattr(sys, '_MEIPASS', os.path.abspath('.'))
    return os.path.join(base, name)

Это нужно, чтобы игра находила картинки и внутри EXE, и при запуске из папки.

RPG‑конструктор / «Уютный уголок»

Сохранения (JSON, SQLite) лучше хранить в %APPDATA% или в папке data/ рядом с EXE. Так прогресс не пропадёт при переустановке.

Частые проблемы и решения

Проблема Решение
Антивирус ругается на EXE Это частый ложный сигнал. Для тестов можно подписывать или распространять как архив с BAT + исходниками.
Картинки не грузятся в EXE Добавь их через --add-data либо используй функцию get_path выше.
Слишком большой EXE Убери лишние зависимости, используй только нужные модули, избегай import *.
Ошибка «Python не найден» в BAT Проверь, добавлен ли Python в PATH, или укажи полный путь к python.exe.
